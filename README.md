# GC-Image-Import
GC Import Images is an extension of the Green Cabinet package for LibreOffice Writer that allows for the batch insertion of images from a selected folder directly into a document. Users can configure image size, spacing, import order, and automatic captions based on file names.

# Features
GC Import obrázků is a handy extension for LibreOffice Writer that simplifies the process of repeatedly inserting images into text documents.

When preparing a document containing dozens of photos, inserting individual files one by one can be tedious. With the GC Import obrázků extension, you can select a folder containing your prepared images and insert them all into the document using a single tool.

The extension also allows you to configure the size of the inserted images. You can choose to automatically fit them to the page width or specify a custom width based on the document's requirements.

# Language Support
The GC Import obrázků extension supports three user interface languages:

- Czech
- Slovak
- English

This multilingual interface makes the extension easy to use for people in different language environments.

# Key Features
- Batch image insertion – insert multiple images from a selected folder into a Writer document.
- Automatic sizing – adjust image width to fit the available page width.
- Custom image width – option to specify a desired width for a consistent document appearance.
- Simple operation – configure insertion settings via a dialog box.
- Time-saving – reduces repetitive manual steps when preparing documents with many images.
- Multilingual interface – supports Czech, Slovak, and English.

# How does the extension work?
- Gather the images you want to insert into a single folder.
- Open a document in LibreOffice Writer.
- Launch the GC Import Images extension.
- Select the folder containing the images.
- Choose automatic resizing or specify a custom width.
- Run the import and check the resulting document layout.

With automatic resizing, images are adjusted to fit the available page width, taking document margins into account. Using a custom width allows you to standardize image dimensions for a specific purpose.

# Who is this extension for?
The extension is suitable for anyone who regularly creates documents containing many images and wants to minimize repetitive manual work. It is useful in offices, schools, and technical documentation, as well as for preparing internal company materials.
